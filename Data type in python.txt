Data type in python:

int:
  whole numbers without decimal numbers
  ex: x=10 y=-5

float:
  number with one and more decimal and exponential value
  ex: price=19.88 gravity=9.8

complex:
   number with a real and an imaginary part
   ex: z=3+5j

string:
   sequence of Unicode characters enclosed in quotes
   ex: name="python"

list:
   An ordered mutable collection that can store mixed data types
   ex: [1,"apple",3.4]

Range:
   Represents a sequence of numbers, commonly used for looping a specific number of time in for loops

Dictionary:
   An unordered (or insertion-ordered since python 3.7) collection where each unique key maps to a value
   ex:{"name":"Alice","age":25}





Arithmetic operaters
Used for mathematical calculations.


+ (Addition) → 5 + 3 = 8


- (Subtraction) → 5 - 3 = 2


* (Multiplication) → 5 * 3 = 15


/ (Division) → 5 / 2 = 2.5


% (Modulus) → 5 % 2 = 1


** (Exponent) → 2 ** 3 = 8


// (Floor division) → 5 // 2 = 2


a = 10b = 3print(a + b)  # 13print(a // b) # 3


2. Comparison (Relational) Operators
Used to compare two values (returns True/False).


== (Equal to)


!= (Not equal to)


> (Greater than)


< (Less than)


>= (Greater than or equal to)


<= (Less than or equal to)


x = 5y = 10print(x < y)   # Trueprint(x == y)  # False


3. Logical Operators
Used to combine conditional statements.


and → True if both conditions are true


or → True if at least one condition is true


not → Reverses the result


a = Trueb = Falseprint(a and b) # Falseprint(a or b)  # Trueprint(not a)   # False

4. Assignment Operators
Used to assign values to variables.


= → Assign value


+=, -=, *=, /= → Combine operation with assignment


x = 5x += 3  # same as x = x + 3print(x)  # 8


5. Bitwise Operators
Work on binary values.


& (AND)


| (OR)


^ (XOR)


~ (NOT)


<< (Left shift)


>> (Right shift)


a = 5   # 101b = 3   # 011print(a & b)  # 1


6. Membership Operators
Check if a value exists in a sequence.


in


not in


nums = [1, 2, 3]print(2 in nums)     # Trueprint(5 not in nums) # True


7. Identity Operators
Check if two variables refer to the same object.


is


is not


a = [1, 2]b = aprint(a is b)  # True
